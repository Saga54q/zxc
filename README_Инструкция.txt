2. КАК СОБРАТЬ ГОТОВУЮ БАЗУ ДАННЫХ «Поликлиника.accdb» (СПОСОБ 1 — В 1 КЛИК)
--------------------------------------------------------------------------------
  1. Распакуйте архив в любую папку на компьютере с ОС Windows и установленным
     пакетом Microsoft Access (2010 / 2013 / 2016 / 2019 / 2021 / Microsoft 365).
  2. Дважды щёлкните по файлу «Создать_БД_Поликлиника.vbs».
  3. Через 5–10 секунд в этой же папке появится полностью собранный файл
     «Поликлиника.accdb» со всеми 13 таблицами, схемой данных, тестовыми
     записями, 16 запросами, 7 формами, 4 отчётами, 6 макросами и ролями доступа.

3. КАК СОБРАТЬ БАЗУ ДАННЫХ ВРУЧНУЮ ИЗ MS ACCESS (СПОСОБ 2)
--------------------------------------------------------------------------------
  1. Создайте в MS Access пустую базу данных «Поликлиника.accdb».
  2. Нажмите Alt+F11 (откроется редактор Visual Basic for Applications).
  3. В меню «File -> Import File...» («Файл -> Импорт файла...») выберите файлы:
       VBA\ModSecurity.bas
       VBA\ModAdmin.bas
       VBA\AutoBuild.bas
  4. Нажмите Alt+F8, выберите макрос «СоздатьБД» и нажмите «Выполнить» (Run).

5. ЧАСТЫЕ ВОПРОСЫ И РЕШЕНИЕ ПРОБЛЕМ
--------------------------------------------------------------------------------
  Вопрос: при запуске скрипта появляется сообщение «Не удалось запустить
          Microsoft Access».
  Ответ:  проверьте, что установлен пакет Microsoft Access (не только Word и
          Excel) версии 2010 или новее. Скрипт использует объектную модель
          Access (Application.CreateForm / LoadFromText), которая появилась
          начиная с Access 2007/2010.

  Вопрос: скрипт сообщает, что файл «Поликлиника.accdb» занят.
  Ответ:  закройте базу данных в MS Access и запустите скрипт повторно.

  Вопрос: при сборке появилось сообщение о замечаниях (ошибках).
  Ответ:  сборщик ведёт журнал построения. Каждый объект создаётся независимо
          от остальных, поэтому одна ошибка не прерывает всю сборку. Полный
          журнал выводится в диалоговом окне и доступен в редакторе VBA
          (Alt+F11 -> Ctrl+G, окно Immediate). Повторный запуск процедуры
          «СоздатьБД» (Alt+F8) полностью пересоздаёт базу данных.

  Вопрос: при открытии готовой базы данных Access показывает жёлтую полосу
          безопасности «Предупреждение системы безопасности».
  Ответ:  нажмите «Включить содержимое» (Enable Content) — в базе используются
          макрос и программный код VBA.

  Примечание по имени вычисляемого поля запроса Q07_СтоимостьЛечения.
  В MS Access имя поля (Alias) не может содержать символы «.» и «,»: при
  создании запроса с именем вида «Сумма, руб.» возникает ошибка 3126
  «Недопустимое использование скобок». Поэтому вычисляемое поле названо
  «Сумма руб»; на оформление и итоги отчётов это не влияет.
